🍽️ Restaurant Menu Web App

A simple and interactive restaurant menu built using HTML, CSS, and JavaScript. Users can add items to their order, manage quantities, and generate a receipt in real-time.

⸻

🚀 Features
• 📋 View menu items with prices
• ➕ Add items to your order
• 🔢 Increase / decrease item quantity
• 🧾 Live order summary
• 💲 Automatic total calculation
• ❌ Remove items from order
• 🧹 Clear entire order
• 🧾 Checkout system with receipt
• 🕒 Displays date & time on receipt
• ⚡ Real-time UI updates
• 💡 Clean and beginner-friendly code

⸻

🛠️ Technologies Used
• HTML
• CSS
• JavaScript
