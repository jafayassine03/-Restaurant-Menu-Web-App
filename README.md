🍽️ Restaurant Menu Web App

A simple and interactive restaurant menu built using HTML, CSS, and JavaScript. Users can add items to their order and see the total update in real-time.

⸻

🚀 Features
	•	📋 View menu items with prices
	•	➕ Add items to your order
	•	🧾 Live order summary
	•	💲 Automatic total calculation
	•	💡 Clean and beginner-friendly code

⸻

🛠️ Technologies Used
	•	HTML
	•	CSS
	•	JavaScript
